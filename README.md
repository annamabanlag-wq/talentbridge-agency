## Vercel Deployment Notes
This is a Node.js HTTP server with file-based persistence. For free Vercel hosting:
1. Go to https://vercel.com
2. Import this GitHub repository
3. Set the root directory and use a custom build or note that full server + filesystem persistence has limitations on serverless platforms
4. Recommended alternative for free persistent hosting: Railway, Render, or Fly.io
